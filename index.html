About this course

This is a first-year programming course taught in C and C++. It starts from the very beginning — how a program is written, turned into something the computer can actually run, and made to do useful work — and builds up over the semester to arrays and pointers, functions, files, memory you manage yourself, and a closing look at how the same language is used for artificial intelligence.

Each chapter is a single web page you can open on any device. Wherever an idea is easier to see than to read about — how a value is laid out in memory, how a loop steps through data, how a program is assembled from its parts — it becomes a small animation you can play and replay at your own pace. No installation and no internet connection are needed once a chapter has opened.

What each lecture covers

A one-line preview of all nineteen lectures (L0–L18).

  1. Course OrganizationHow the course runs — the schedule, the grading map, lab rules, the AI-use policy, and what you need to get started.
  2. Getting Started with CThe C language and its tools — how you turn source code into a running program (edit → compile → link → run).
  3. Data Types & OperatorsThe kinds of values a C program stores — integers, real numbers and characters — how they are declared and combined.
  4. Arithmetic & ComputationDoing maths in C — operators and precedence, integer versus floating-point behaviour, and how numbers can overflow.
  5. Input & OutputReading from the keyboard and printing to the screen with printf/scanf and format specifiers.
  6. Conditionals & LoopsMaking decisions and repeating work — if, switch, for, while and do-while.
  7. Arrays & PointersStoring many values together, and pointers — the addresses that let C reach into memory directly.
  8. StringsText in C — character arrays, the standard string functions, and the classic pitfalls to avoid.
  9. Functions & RecursionBreaking a program into reusable functions — parameters, scope, the call stack, and recursion.
  10. File I/OReading and writing files — opening and closing, text versus binary, and handling errors.
  11. Dynamic MemoryAsking for memory while the program runs — malloc/calloc/realloc/free and avoiding leaks.
  12. Structs & UnionsBuilding your own data types — struct, union, typedef, and nesting them.
  13. MultithreadingDoing several things at once — threads, synchronization, and the race conditions to watch for.
  14. AI Algorithms in C++Classic machine-learning methods coded from scratch — linear regression, Naïve Bayes and k-means.
  15. AI on HardwareRunning AI fast — GPUs and CUDA, FPGAs, and shrinking models so they fit and run efficiently.
  16. Vibe Coding & AI AssistanceUsing AI tools to help you write code — what they are good for, and doing it responsibly.
  17. Preprocessor & Build SystemsSplitting a program across files and building it — the preprocessor, Makefiles and CMake.
  18. Standard LibrariesThe ready-made toolbox — stdlib, string.h, time.h, ctype.h, and a first look at the C++ STL.
  19. Data Structures & ComplexityThe capstone — lists, stacks, queues, sorting, hashing, and measuring an algorithm's cost with Big-O.
