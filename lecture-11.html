Structs and Unions

Grouping related fields; pointers to structs; typedef; nested structures; arrays and dynamic allocation; unions for space efficiency

§1 · Why Group Related Data?

Parallel arrays force you to keep indices synchronized by hand. A struct groups related fields into one logical unit — all fields move together.

Imagine three arrays: names[], ids[], grades[]. When you sort, copy, or pass students around, you must remember to move all three. A struct solves this: it bundles all fields of one student into a single type, so they travel together automatically.

§2 · Struct Definition and Usage

Define a struct Student with three fields. Use typedef to name the type, so you write Student s; instead of struct Student s;.

Member access uses the dot operator. Struct assignment copies all fields:

typedef struct {
    int    id;
    char   name[50];
    double grade;
} Student;

Student s = { 1001, "Ali", 87.5 };    // positional init
printf("%s: %.1f\n", s.name, s.grade); // dot operator
s.grade = 92.0;
Alignment note: the compiler adds invisible padding bytes between members for alignment. sizeof(Student) may exceed the sum of its members' sizes.

§3 · Pointers to Structs — the Arrow Operator

When you have a pointer to a struct, use ptr->member instead of (*ptr).member. The arrow "follows" the pointer.

Both forms are equivalent, but -> is clearer and preferred:

Student  s   = { 1001, "Ali", 87.5 };
Student *ptr = &s;

ptr->grade = 90.0;  // same as (*ptr).grade

The arrow operator ptr->field automatically dereferences the pointer and accesses the field. Each field is one piece of a larger whole, and all fields share the same memory block.

§4 · Arrays of Structs

Create an array of students: Student list[30]; Each element is a complete struct, accessible by index.

Access each struct's members with the dot operator, and use struct assignment to swap or copy:

Student list[5] = {
    {1001, "Ali", 87.5}, {1002, "Sara", 92.0}, {1003, "Omar", 78.5},
    {1004, "Fatima", 95.5}, {1005, "Yusuf", 83.0}
};

// find top scorer
int top = 0;
for (int i = 1; i < 5; i++)
    if (list[i].grade > list[top].grade) top = i;

// full copy: all fields move together
Student tmp = list[0];
list[0] = list[1];
list[1] = tmp;  // swap — works correctly

§5 · Dynamic Arrays of Structs

Combine malloc with structs to allocate an array of students at runtime.

Always free the memory when done. The ownership rule: whoever allocates is responsible for freeing:

int n = 30;
Student *arr = malloc(n * sizeof(Student));
if (!arr) { perror("malloc"); exit(1); }

// fill and access via index or pointer arithmetic
arr[0].id = 1001;
arr[0].grade = 87.5;

free(arr);  // return memory to heap
arr = NULL;
Ownership: if a function allocates and returns a pointer, the caller is responsible for calling free. Document this in the function comment.

§6 · Unions — Shared Memory

A union allocates enough memory for its largest member. All members share that same region — writing one overwrites the others.

Unions are rare but useful for space-constrained systems. A tagged union pairs a union with an enum that records which member is active:

typedef enum { INT_VAL, FLOAT_VAL } ValType;
typedef struct {
    ValType type;
    union { int i; float f; } val;
} Variant;

Variant v = { FLOAT_VAL, { .f = 2.718f } };
if (v.type == FLOAT_VAL)
    printf("%.2f\n", v.val.f);  // safe to read .f
Critical: Always check the tag before reading from the union. Reading the wrong member is undefined behavior.
