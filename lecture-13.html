§1 · Why C/C++ for AI on Embedded Systems?

Python + PyTorch handles most AI today — but embedded systems (microcontrollers, robots, smart sensors) have no Python runtime, limited RAM, and must respond in milliseconds.

C/C++ gives full control: no garbage collector, no runtime overhead, fine-grained memory use. You can implement even sophisticated AI algorithms in a few hundred bytes of RAM. This lecture surveys the classic algorithms that power embedded AI.

§2 · Linear Regression with Gradient Descent

The simplest supervised learning algorithm. Model: y = w·x + b. Learning: iteratively adjust weights to minimize error.

Gradient descent computes the derivative of loss with respect to each weight, then moves in the opposite direction:

double w = 0.0, b = 0.0;
double alpha = 0.01;  // learning rate

for (int epoch = 0; epoch < 100; epoch++) {
    double dw = 0.0, db = 0.0;
    for (int i = 0; i < n; i++) {
        double error = (w * x[i] + b) - y[i];
        dw += error * x[i];
        db += error;
    }
    w -= alpha * (2.0 / n) * dw;
    b -= alpha * (2.0 / n) * db;
}
Hyperparameters: alpha (learning rate): too large diverges, too small converges slowly. epochs: more epochs lower error but risk overfitting.

§3 · Naïve Bayes Classification

Assume features are independent given the class. Compute log probabilities to avoid numerical underflow:

Training: count occurrences. Prediction: sum log probabilities of each feature given the class, then argmax:

// Training: for each class and feature, record P(feature | class)
double log_prob_spam = log(prior_spam);
for (int f = 0; f < n_features; f++) {
    if (feature[f])
        log_prob_spam += log(p_word_given_spam[f]);
}
// Compare with log_prob_ham, predict the higher
Laplace smoothing: when a feature never appeared in training, log(0) crashes. Add 1 to all counts: P(w|c) = (count + 1) / (total + vocab_size).

§4 · K-Means Clustering

Partition n points into k clusters. Algorithm: choose k random centroids, assign points to nearest centroid, update centroids, repeat.

Each iteration is O(n·k), and typically converges in 10–20 iterations, making it fast even on modest hardware:

for (int iter = 0; iter < max_iters; iter++) {
    // Assign each point to nearest centroid
    for (int i = 0; i < n; i++) {
        double best = 1e18;
        for (int c = 0; c < k; c++) {
            double dist = euclidean(points[i], centroids[c]);
            if (dist < best) {
                assignment[i] = c;
                best = dist;
            }
        }
    }
    // Update centroids

}

§5 · Quantization and Pruning

Reduce model size without sacrificing accuracy. Quantization reduces precision (32-bit float → 8-bit int). Pruning removes small weights.

On a microcontroller with 32 KB RAM, storing a dense neural network is impossible. Quantization cuts memory by 4x; pruning can cut it by 10x. Combined: a model that runs on a smartwatch.

// Quantization: map [min, max] to [0, 255]
uint8_t quantized = (uint8_t)((value - min) / (max - min) * 255);
// Dequantize during inference
double dequantized = min + (quantized / 255.0) * (max - min);

// Pruning: zero out weights below a threshold
for (int i = 0; i < n_weights; i++)
    if (fabs(weights[i]) < threshold)
        weights[i] = 0.0;
Accuracy trade-off: quantization typically causes 1–2% accuracy loss. Pruning depends on sparsity; removing 50% of weights causes 1–5% loss. Both are usually worth the speedup and memory savings.

§6 · Decision Trees

A simple, interpretable classifier. Build a binary tree where each node tests a feature; leaves are class predictions.

Decision trees are fast to evaluate (just a series of if-then tests), use little memory, and are popular on embedded systems:

// Predict using a pre-built tree
int predict(DataPoint *x, TreeNode *node) {
    if (node->is_leaf)
        return node->class_label;
    if (x->features[node->split_feature] < node->split_threshold)
        return predict(x, node->left);
    else
        return predict(x, node->right);
}
Training: recursively split on the feature that maximizes information gain (entropy reduction). Overfitting: deep trees memorize training data; limit depth and require minimum samples per leaf.
